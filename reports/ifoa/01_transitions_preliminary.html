Economic Status Transitions: Employed and Long-term Sick

Preliminary Analysis for IFoA Collaboration

Author

Jon Minton (Public Health Scotland)

Published

January 19, 2026

1 Preamble: Scope and Analytical Choices

This preliminary report addresses the IFoA brief to examine transitions between Employed and Long-term Sick economic statuses using the UK Household Longitudinal Study (UKHLS). Before presenting results, we explicitly document the analytical choices made to ensure transparency and reproducibility.

1.1 Pre-specification of Analytical Decisions

To minimise researcher degrees of freedom, we document the following decisions made before analysing the data: | Decision | Choice | Rationale | |———-|——–|———–| | Data source | UKHLS waves 1-11 (2009-2021) | Largest UK panel study with economic status | | Transition definition | Adjacent waves only | Avoids complications of variable gap lengths | | Age range | 16-64 (working age) | Standard UK working age definition | | Economic status categories | 7-level (Level 3) | Distinguishes LT Sick from other inactive | | Health measures | SF-12 MCS/PCS (continuous) | More granular than binary measures | | Occupation classification | NS-SEC 3-class | Balance between detail and cell counts | | Missing data | Complete cases only | Avoids imputation assumptions | | Model type | Multinomial logistic regression | Standard for categorical outcomes |

1.2 Alternative Interpretations Not Pursued (Yet)

The IFoA brief could reasonably be interpreted in other ways:

  1. Longer transition gaps - e.g., 2-year or 5-year transitions
  2. NS-SEC 5-class or 8-class - more occupational detail but sparser cells
  3. Binary health measure - limiting long-term illness (yes/no)
  4. Imputed missing data - could increase sample size

These alternatives can be explored in subsequent analyses if the IFoA considers them valuable.

# Extract NS-SEC 3-class for each wave
nssec_data <- lapply(letters[1:11], function(w) {
  filepath <- here::here(base_dir_location, paste0(w, "_indresp.dta"))
  if (!file.exists(filepath)) return(NULL)
  tryCatch({
    df <- read_dta(filepath, col_select = c("pidp", paste0(w, "_jbnssec3_dv")))
    names(df) <- c("pidp", "nssec3_raw")
    df$wave <- w
    df
  }, error = function(e) NULL)
}) %>% bind_rows()

# Clean NS-SEC values
nssec_clean <- nssec_data %>%
  mutate(
    nssec3 = case_when(
      nssec3_raw < 0 ~ NA_character_,
      nssec3_raw == 1 ~ "Management & professional",
      nssec3_raw == 2 ~ "Intermediate",
      nssec3_raw == 3 ~ "Routine",
      TRUE ~ NA_character_
    )
  ) %>%
  select(pidp, wave, nssec3)

# Merge with main data
ind_data_standardised <- ind_data_standardised %>%
  left_join(nssec_clean, by = c("pidp", "wave"))

5 Multinomial Logistic Regression Models

Model Fitting Note

Multinomial logistic regression models for these transitions require significant computation time and many iterations (typically maxit = 1000 or more) to properly converge. Following the approach in Minton et al. (2024), models should be:

  1. Fitted using nnet::multinom() with the specification: next_status ~ this_status * sex + splines::bs(age, 5) + health_predictors
  2. Run with sufficient iterations for convergence
  3. Results cached for reproducibility

For this preliminary report, we present the descriptive results above. Full model results can be obtained by running the models separately (e.g., in an R script) and loading the cached results.

5.1 Model Specification (For Reference)

The foundational model specification from the existing papers is:

nnet::multinom(
  next_status ~ this_status * sex + splines::bs(age, 5) + sf12mcs_dv + sf12pcs_dv,
  data = ind_data_standardised,
  maxit = 1000  # or higher for convergence
)

This models:

  • Current state (this_status): Captures path dependence
  • Sex with interaction: Different transition patterns by sex within each origin state
  • Age (spline): Flexible non-linear age effects
  • Health scores: SF-12 mental and physical component scores (standardised)

6 Summary and Next Steps

6.1 Key Findings (Preliminary)

  1. Employed → LT Sick transitions are relatively rare but show clear patterns:
    • Higher rates at older ages
    • Associated with poorer mental and physical health
    • Occupation class gradient visible
  2. LT Sick → Employed transitions:
    • More common at younger ages
    • Strongly associated with better health scores
    • Management/professional occupations show higher return-to-work rates

6.2 Limitations

  • Model convergence: With maxit = 100, models may not have fully converged. Production analysis should use maxit = 1000.
  • Missing NS-SEC: Occupation data is only available for those currently/recently employed.
  • Causal interpretation: These are associations, not causal effects.

6.3 Questions for IFoA Discussion

  1. Is NS-SEC 3-class sufficient, or would 5-class be preferred?
  2. Should we also examine 2-year or longer transitions?
  3. Additional covariates: Region, education, industry sector?
  4. Comparison with administrative data?
